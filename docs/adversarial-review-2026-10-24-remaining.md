# 적대적 검토 잔여 항목 분류 (2026-10-24) — **전부 처리 완료**

- 수리 완료: 46건(P0 2·P1 18·P2 14·P3 6 — `implementation_plan.md` §8), 사실 확인 기각 1건(ICY NUL — `RadioTrack.ParseStreamTitle`의 `TrimEnd('\0')`이 이미 커버).
- **본 문서의 잔여는 2026-10-24 사용자 "전부 승인"으로 전부 처리됨**: A 26건·B 15건 수리,
  C 8건 폐기 기록, D 3건 확인(§9 — D2는 프로젝션 부재 확인으로 죽은 호출 정리, D3는 유예 10s
  수리, D1은 하단 수동 확인 절차). 수리 내역은 `implementation_plan.md` §9.

## D1 수동 확인 절차 (비재현 판정용)

1. 설정에서 "트레이로 닫기" ON → 창을 트레이로 숨김.
2. Windows 시작 메뉴 → 전원 → "종료"를 시도한다.
3. **판정**: 종료 화면으로 바로 진행되면 비재현(현상 없음). "Dawn Player에서 앱이 종료를 방지하고
   있습니다" 차단 화면이 뜨면 재현 — WM_QUERYENDSESSION/WM_ENDSESSION 서브클래싱으로
   `AppWindow.Closing`의 트레이 숨김 cancel을 종료 요청에 우회시키는 수리를 착수한다.
   (WinUI 3의 AppWindow.Closing이 시스템 종료 요청에도 발화하는지는 OS/SDK 버전별로 갈린다.)
